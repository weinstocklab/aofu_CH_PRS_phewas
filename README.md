# aofu_CH_PRS_phewas

Analysis scripts and workflow components for PheWAS studies involving clonal hematopoiesis (CH) and polygenic risk scores (PRS).

## Scientific context

This repository supports hypothesis-driven analyses of relationships between CH-related exposures and broad phenome outcomes, including effect-modification and risk-stratification analyses using PRS. The workflow is intended for reproducible, research-focused PheWAS analyses in controlled-access biomedical data settings.

## Repository structure

- `workflow/Snakefile`: Snakemake workflow entry point.
- `workflow/scripts/`: Python and R scripts used for data preparation, querying, and PheWAS analyses.
- `docs/`: Supporting SQL and R scripts for condition processing and figure generation.
- `requirements.txt`: Python package requirements.

## Setup and requirements

This repository uses Python for workflow execution and analysis scripts, with some R scripts for downstream plotting/figure generation.

**Execution environment:** This workflow is intended to be run in the **All of Us Researcher Workbench** environment.

### Python environment

```bash
cd /path/to/aofu_CH_PRS_phewas
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

If you use Conda:

```bash
conda create -n aofu_ch_prs_phewas python=3.10 -y
conda activate aofu_ch_prs_phewas
pip install -r requirements.txt
```

### R environment (where relevant)

Install R and required R packages used by scripts in `docs/` and `workflow/scripts/` (for example, plotting and data manipulation packages referenced in those scripts).

## Usage

Run the workflow with Snakemake (example/placeholder command):

```bash
snakemake -s workflow/Snakefile --cores 4
```

Run individual analysis scripts directly (examples/placeholders):

```bash
python workflow/scripts/run_phewas.py --help
python workflow/scripts/run_prs_spline_phewas.py --help
python workflow/scripts/run_survival_phewas.py --help
```

## Data

Expected inputs include phenotype/clinical coding data (for PheWAS), CH-related variables, and PRS-derived inputs in project-specific formats consumed by the workflow/scripts.

Do **not** commit protected or sensitive data (including identifiable clinical data, credentials, or access tokens) to this repository.

## Results and output

Primary outputs are expected to include processed phenotype tables and PheWAS result summaries, with optional downstream figures generated by R scripts.

Output locations depend on workflow configuration and runtime parameters used in Snakemake/script execution.
